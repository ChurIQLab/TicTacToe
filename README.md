# TicTacToe

Classic tic-tac-toe for iPhone. Play against the computer or with a friend on the same device.

> Work in progress

## Features

- Play against the computer on three difficulty levels
- Play with a friend on one device and keep the match score
- Choose from eight figures instead of plain X and O
- Light and dark themes
- Move and win animations with haptic feedback
- English and Russian

## Requirements

iOS 17.0+ · Xcode 26+

## Built with

Swift 6 · UIKit · MVP architecture · SwiftLint
